
# マイリスト絞り込み（CLIP STUDIO ASSETS 非公式）

> **これは個人が作った非公式のツールです。** 株式会社セルシス（CLIP STUDIO）とは関係ありません。
> 使って起きたことの責任は持てないので、自己責任でお使いください。

CLIP STUDIO ASSETS の「マイリスト」ページに、こんなボタンを足す Chrome 拡張機能です。
<img width="495" height="212" alt="使用例" src="https://github.com/user-attachments/assets/c9637f40-551c-4e31-b679-ada3f1d31e30" />

- **すべて ／ CLIPPY ／ GOLD ／ 無料** の切り替え
- **標準 ／ 安い順 ／ 高い順** の並べ替え（CLIPPY タブなら CP、GOLD タブなら G の価格で並べます）

ページの表示を並べ替えるだけで、データをどこかに送ったり、アカウントを操作したりはしません。

## 入れ方

1. このページの緑の「**Code**」ボタン →「**Download ZIP**」でダウンロードして、ZIP を展開する
2. Chrome のアドレスバーに `chrome://extensions` と入れて開く
3. 右上の「**デベロッパーモード**」をオンにする
4. 「**パッケージ化されていない拡張機能を読み込む**」を押して、展開したフォルダ（`manifest.json` が入っているフォルダ）を選ぶ
5. マイリスト（https://assets.clip-studio.com/ja-jp/starred ）を開くと、ボタンが出ます

展開したフォルダは、消したり場所を変えたりしないでください（拡張が動かなくなります）。

## 注意

- 並べ替えは、いま表示されているページの中だけです。
- 「すべて」タブで並べ替えると、無料 → G（なければ CP）の順で比べます。G と CP は単位が違うので、きっちり見たいときは CLIPPY か GOLD タブで並べてください。
- サイトの作りが変わると動かなくなることがあります。
